# 교육대학원 연구계획서 작성 에이전트

거친 연구 아이디어를 질문과 비판적 검토를 통해 **지도교수 상담용 석사학위 논문 연구계획서**로 발전시키는 Codex 프로젝트입니다. 교육대학원 학생이 연구 목적을 구체화하고, 연구문제에 맞는 자료 수집과 분석 절차를 설계하도록 돕습니다. 연구의 최종 방향은 사용자가 선택합니다.

## 어떤 도움을 받을 수 있나요?

- 한 문장으로 시작한 아이디어에서 연구할 질문을 찾습니다.
- 연구 대상, 지도 기간, 확보할 수 있는 자료를 확인하며 실행 가능성을 검토합니다.
- 연구방법의 대안과 각 방법의 부담·한계를 쉬운 말로 비교합니다.
- 연구 목적, 연구문제, 자료 수집, 분석방법이 서로 연결되는지 점검합니다.
- 확인된 내용과 아직 정하지 못한 내용을 구분하여 계획서 초안을 작성합니다.

기본 관심사는 중학교 수학의 기초가 충분히 형성되지 않은 고등학교 1학년 학생 지도입니다. 다른 학년이나 교과를 연구하려면 첫 대화에서 자신의 주제와 상황을 알려주세요. 기본 맥락을 그대로 따를 필요는 없습니다.

## 처음 사용하는 방법

1. 이 저장소를 자신의 컴퓨터에 받습니다. GitHub 저장소의 ZIP 다운로드를 이용하거나, Git이 설치되어 있다면 아래 명령으로 복제할 수 있습니다.

   ```bash
   git clone https://github.com/angelboymo3/research-proposal-agent.git
   ```

2. Codex에서 받은 폴더를 프로젝트로 열고 대화를 시작합니다. 첫 메시지에 “이 프로젝트의 AGENTS.md를 읽고 지침에 따라 도와줘”라고 적으면 작업 기준을 명확히 전달할 수 있습니다. 문서 작업을 시작하기 위해 Gemini API 키나 별도 스킬을 설치할 필요는 없습니다.

3. 관심 있는 현상과 현장 경험을 자신의 말로 적습니다. 알고 있는 학년, 지도 내용, 기간, 자료 확보 여건만 알려주세요. 아직 모르는 부분은 “미정”이라고 답하면 됩니다.

4. 에이전트가 한 번에 최대 3개의 핵심 질문을 제시하면 답합니다. 제안된 연구방법의 장단점을 함께 검토하고 자신에게 가능한 방향을 선택합니다.

5. 연구 목적, 연구문제, 방법과 남은 미정 사항을 확인한 뒤 초안 작성을 요청합니다. 학교나 지도교수의 지정 양식이 있다면 함께 제공합니다.

6. 결과를 파일로 남기려면 저장할 이름을 명시합니다. 처음에는 기존 예시를 보존하도록 `내_연구계획서.md` 등 다른 이름을 권장합니다. 초안을 읽고 지도교수 상담 결과를 전달하여 수정합니다.

GitHub에 올리는 것은 별도 작업입니다. 자신의 계획서를 공개할 필요는 없으며, 이 저장소를 복제했다고 원본 저장소에 쓰기 권한이 생기는 것은 아닙니다.

## 예시 입력

### 아이디어부터 시작하기

아래 내용을 복사한 뒤 자신의 상황에 맞게 바꿔보세요.

```text
이 프로젝트의 AGENTS.md를 읽고 지침에 따라 도와줘.
나는 교육대학원 학생이고, 중학교 수학의 기초가 충분하지 않은
고등학교 1학년 학생을 지도하는 연구를 생각하고 있어.
내 상황에 맞는 연구문제를 찾고 싶어.
아직 인원과 지도 기간은 미정이야. 먼저 필요한 질문부터 해줘.
```

이 단계에서는 바로 완성된 계획서를 쓰기보다, 어떤 학습 내용에서 어려움이 나타나는지와 실제로 지도·관찰할 수 있는 여건부터 확인합니다.

### 저장소의 예시 초안과 같은 아이디어 사용하기

```text
중학교 수학 시간에 Gemini Live API로 음성 퀴즈 웹앱을 만들고 싶어.
이 아이디어를 교육대학원 논문 연구로 발전시키려면 무엇을 정해야 할까?
웹앱 개발과 교육 연구의 초점을 구분해서 질문해줘.
```

예상되는 첫 질문은 다음과 같습니다. 이는 대화 흐름의 예시이며, 답을 미리 정해 둔 것은 아닙니다.

- 연구의 중심은 웹앱의 사용성, 학생의 참여 경험, 특정 수학 내용의 학습 과정 중 무엇인가요?
- 적용할 학년·단원·참여 인원·지도 기간은 어떻게 되나요?
- 학생 음성 전송과 관련된 학교 승인·보호자 동의·서비스 이용 조건을 확인했나요?

### 아직 미정인 상태에서 초안 요청하기

```text
아직 대상과 기간은 미정이지만 지도교수 상담용 초안이 필요해.
정하지 않은 내용은 [미정], 내가 확인할 내용은 [사용자 확인 필요],
문헌 근거가 필요한 곳은 [문헌 확인 필요]로 표시해줘.
기존 예시는 보존하고 내_연구계획서.md로 저장해줘.
본문 뒤에 남은 미정 사항과 지도교수에게 확인할 질문도 정리해줘.
```

## 산출물: 연구계획서.md 읽는 법

현재 [연구계획서.md](연구계획서.md)는 **미정 사항을 남기는 규칙을 시험한 예시 초안**입니다. 실제 연구가 수행되었거나 설계가 확정되었다는 뜻은 아닙니다. 문서 앞부분에는 입력 아이디어와 작성 전 질문이 있고, 본문은 다음 순서로 구성되어 있습니다.

1. 연구 제목
2. 연구의 필요성 및 목적
3. 연구문제
4. 이론적 배경 및 선행연구
5. 연구방법: 설계, 참여자, 수업 절차, 자료 수집·분석, 연구윤리
6. 기대효과 및 한계
7. 연구 일정
8. 참고문헌

본문 뒤에는 남은 미정 사항과 지도교수 상담 질문을 따로 정리합니다. 연구방법의 표에서는 각 연구문제에 어떤 자료와 분석방법이 대응하는지 확인할 수 있습니다.

| 표시 | 의미와 다음 할 일 |
| --- | --- |
| `[미정]` 또는 `[학년]`, `[단원]` | 아직 정하지 않은 설계 요소입니다. 실제 여건을 확인하고 채웁니다. |
| `[사용자 확인 필요]` | 사용 조건, 학교 승인 등 사용자가 확인해야 할 사항입니다. |
| `[문헌 확인 필요]` | 뒷받침할 출처를 아직 확인하지 못한 주장입니다. 관련 문헌을 검토한 뒤 보완합니다. |

예시의 실행연구 또는 질적 사례연구는 제안 단계입니다. Gemini Live API의 기능·이용 조건과 선행연구도 검증하지 않은 상태이며, 확인된 인용 문헌이 없어 참고문헌 목록을 채우지 않았습니다. 예시를 그대로 제출하기보다 자신의 설계와 확인된 근거로 수정해야 합니다.

## 자료를 제공하고 초안을 검토할 때

- 학생 이름, 학번, 연락처 등 식별정보는 입력하거나 공개 저장소에 올리지 마세요. 사례는 가명이나 참여자 코드로 설명합니다.
- 실제 학생 음성이나 식별 가능한 자료를 외부 서비스에 넣기 전에 학교 규정, 동의 범위, 자료 처리 조건을 확인합니다.
- 논문이나 학교 양식을 제공하면 해당 자료에 맞춰 작업을 요청할 수 있습니다. 출처에 접근하지 못한 부분은 확인 필요 표시를 유지합니다.
- 인용과 참고문헌은 원자료와 대조합니다. 초록만 확인한 내용과 원문을 확인한 내용을 구분하며, 기본 참고문헌 형식은 APA 7판입니다.
- 예상 효과를 실제 결과로 해석하지 않습니다. 소규모 연구나 비교집단 없는 설계에서 말할 수 있는 범위는 지도교수와 함께 검토합니다.

초안은 지도교수 상담과 후속 검토를 위한 출발점입니다. 남은 확인 사항을 하나씩 해결하면서 자신의 연구계획서로 발전시켜 보세요.
